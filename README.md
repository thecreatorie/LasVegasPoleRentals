# LVPR — Las Vegas Pole Rentals

A Vegas-entertainment Astro rebuild of [lasvegaspolerentals.com](https://lasvegaspolerentals.com).
Dark canvas, triple-neon accents, scroll-driven motion. Generated by the `site-transfer` plugin.

## What's in this folder

- **`src/`** — Astro source. Components, layouts, pages, styles, content.
- **`public/`** — Static assets served verbatim (favicon, OG image).
- **`astro.config.mjs`** — Build config (site URL, redirects, sitemap, compress).
- **`package.json`** — Astro 4, fontsource for Domine + Open Sans Variable, sitemap, compress, sharp.
- **`_migration/`** — Migration artifacts (inventory, brand, raw HTML, downloaded assets). **Gitignored** — never shipped to production.

## Motion system

All motion respects `prefers-reduced-motion: reduce` and uses `transform`/`opacity` only.

- **Hero parallax** — product photo translates Y by 25% across first viewport (throttled rAF).
- **Section reveals** — opacity + 32px translate-up, triggered at 15% in view, once only.
- **Stagger cascade** — direct children of `[data-reveal-stagger]` use 80ms-stepped delays.
- **Stat count-ups** — cubic ease-out, 1000ms, triggered at 50% in view.
- **Marquees** — CSS `@keyframes` translate. Pause on hover/focus.
- **Sticky CTA** — slides in from bottom after 60% viewport scroll. Spring easing.
- **Neon scroll progress** — `animation-timeline: scroll()` where supported, rAF fallback.
- **Header shrink** — transparent over hero, frosted-blur after 32px scroll.
- **Chasing lights** — six dots cycle clockwise around the LVPR wordmark.
- **Ambient orbs** — two blurred radial gradients drift behind the hero.

## First-time setup (your machine)

```bash
cd "Site Transfer Process/LVPR"
npm install
npm run dev
```

Open `http://localhost:4321` for the homepage, or `http://localhost:4321/_theme-preview/` for the full token + component preview.

> **Heads up:** the Cowork sandbox cannot complete `npm install` (writes get partial under read-only mounts). Running `npm install` on your local machine works clean. ~60s.

## Content rebuild

The next phase (`rebuild-content`) reads `_migration/site-inventory.json` and:

- Recreates `src/pages/rent-a-pole.astro`, `view-photos.astro`, `testimonials.astro`, `faqs.astro`, `contact.astro` from the source page bodies.
- Skips dropped pages (`/checkout/`, `/my-cart/`, `/my-account/` — already in `astro.config.mjs` redirects).
- 301s `/rentapole/` → `/rent-a-pole/` (already in `astro.config.mjs`).
- Replaces the broken London-Eye map on `/contact/` with a service-area graphic.
- Adds a real Formspree-backed contact form to `/contact/`.

## Required env vars (for the contact form)

Create `.env`:

```
PUBLIC_FORMSPREE_CONTACT=https://formspree.io/f/your-id
```

The form action in `ContactForm.astro` reads from `import.meta.env.PUBLIC_FORMSPREE_CONTACT`.

## Accessibility

- One `<h1>` per page (fixes the 11-of-12-missing issue from the WordPress source).
- Skip link, semantic landmarks (`<header>`, `<nav>`, `<main>`, `<footer>`, `<article>`).
- Focus rings via `:focus-visible` use a purple `box-shadow` (no outline conflicts).
- All touch targets ≥ 44×44px.
- Mobile nav drawer traps focus and closes on Escape.
- Marquees, parallax, count-ups, glow pulses fall back to instant/opacity-only under `prefers-reduced-motion`.
- All images require alt via the `Picture.astro` wrapper.
